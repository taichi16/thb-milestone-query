省道里程座標查詢系統

本系統將交通部公路局每月更新之「省道里程坐標（里程牌標誌）」開放資料（資料集 ID: 7040），自動打包並導入快取，提供使用者快速查詢與導航定位功能。

系統特色

  • 全自動同步：每日定時透過 GitHub Actions 自主比對政府最新版本，若有變更即自動拉取，確保資料最新。
  • IndexedDB 高速快取：採用瀏覽器資料庫快取 30,000+ 筆資料，首次加載後，後續開啟秒級呈現，且耗費極低流量。
  • 免 API 金鑰地圖：整合開源 Leaflet.js 與 OpenStreetMap 網頁地圖，操作流暢、縮放自如。
  • 一鍵導航：整合 Google 地圖導航 API，手機點選即可直接喚醒 Google Maps App 開始導航。

原始資料來源：政府資料開放平臺 (ID: 7040)
